## How to capture

1. Run the app locally: `npm run dev`.
2. Desktop shots: use your browser's normal window at ~1280px wide.
3. Mobile shot: open DevTools → toggle device toolbar → pick an iPhone-sized viewport (or resize the window to ~390px).
4. Save each capture over the matching placeholder file in this folder, keeping the same filenames so the main `README.md` links stay valid.
